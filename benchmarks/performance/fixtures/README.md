# Fixtures

Генератор использует только обезличенные идентификаторы `FIX-*`/`SESSION-FIX-*`/`RUN-FIX-*`, фиксированные timestamps и synthetic descriptions. Размеры: small=100, medium=1000, large=5000, xlarge=10000 tickets; manifest фиксирует состояния, session и ledger dimensions. Titles, descriptions, prompts, run payloads и любые production identifiers запрещены в committed artifacts.
